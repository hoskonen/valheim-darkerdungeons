# Darker Dungeons

Makes Black Forest crypts darker, moodier, and more reliant on real light sources while preserving Valheim’s vanilla atmosphere.

## Features

- Darker Black Forest crypt interiors
- More atmospheric dungeon exploration
- Makes torches and other light sources feel more meaningful
- Configurable through BepInEx Configuration Manager

## Requirements

- BepInEx for Valheim

Optional:
- BepInEx Configuration Manager

## Installation

Copy the mod folder into your:

BepInEx/plugins/

directory.

## Known issues

Valheim interiors can sometimes show minor fog or torchlight flickering. This also occurs in vanilla gameplay, but darker environments may make it more noticeable.
