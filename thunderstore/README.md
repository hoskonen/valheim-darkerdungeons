# Darker Dungeons

**Bring a torch. The crypts have grown darker.**

Darker Dungeons makes Black Forest crypts darker, moodier, and more reliant on real light sources while preserving Valheim’s vanilla atmosphere.

The goal is simple: make crypt exploration feel more tense and immersive without changing combat, loot, enemies, or dungeon layouts.

## Features

- Darker Black Forest crypt interiors
- Makes torches, lanterns, and other light sources feel more meaningful
- Configurable darkness and fog settings
- Works as a lightweight client-side visual/atmosphere tweak

## Configuration

The mod can be configured through the BepInEx config file or with BepInEx Configuration Manager.

Available settings include:

- Enable or disable the mod
- Crypt ambient brightness multiplier
- Crypt fog color multiplier
- Crypt light intensity multiplier
- Crypt fog density multiplier
- Debug logging

## Known Issues

Valheim interiors can sometimes show minor fog or torchlight flickering. This also occurs in vanilla gameplay, but darker environments may make it more noticeable.
